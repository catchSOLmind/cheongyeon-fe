# cheongyeon-fe

Mobile-first web app frontend.

---

## Tech Stack

- **Core**: React · TypeScript · Vite · React Router
- **상태 관리**: Zustand · TanStack Query · Axios
- **스타일 / UI**: Tailwind CSS · Framer Motion · Kakao SDK
- **배포**: GitHub Actions → AWS S3 · CloudFront

> 버전 및 상세 내용은 [docs/tech-stack.md](docs/tech-stack.md) 참고
